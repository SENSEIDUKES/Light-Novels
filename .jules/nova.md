## 2024-05-18 - Reader Chamber Controls Popover Interaction   **Learning:** Custom UI popovers in the reading experience, such as `ImmersionSettings`, often lack "click-outside" handlers. Because these controls frequently float over active reading text or system elements, forcing users to click a specific toggle button again to close them creates unnecessary friction.   **Action:** When working on temporary floating UI panels or setting dropdowns, standard practice in this application should be to include a document-level `mousedown` event listener via `useEffect` tied to a container `useRef` to allow dismissal by clicking anywhere outside the active panel.
