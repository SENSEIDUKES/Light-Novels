## 2024-05-18 - Visual Personalization Pattern
**Learning:** Adding cosmetic preferences via `ReaderPreferences` allows users to select curated visual styles (like dividers) without adding bloat to the UI. Conditional rendering of these elements in standard layout components (like `ReaderViewport`) keeps the core app lightweight and maintainable, leveraging existing utility classes and `text-portal` / `text-gold-accent` tokens for a seamless aesthetic.
**Action:** When adding new optional cosmetics, continue to extend `ReaderPreferences` and use predefined UI themes and color tokens to maintain visual harmony.
