## 2025-02-12 - Missing offloaded chapter content in HTML export   **Learning:** Functions generating exports might silently skip offloaded chapter content if they assume `chapter.generatedContent` is always loaded in memory.   **Action:** Always hydrate data asynchronously from storage for exports when `hasContent` is true but the content string is missing.
## 2025-02-12 - Consistency checks and Hash generation silently skip offloaded chapters   **Learning:** The checkConsistency and sealChapter methods in useChapterLock failed to hydrate content before reading it, causing them to hash an empty string and lock an empty chapter, causing permanent silent data loss. **Action:** Any feature reading `generatedContent` from memory must actively fetch from `storyStorage` when `hasContent` is true but `generatedContent` is falsy.
